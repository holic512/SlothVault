# 统一登录与会话生命周期

## 登录入口

- 普通用户和管理员都使用 `/login`，默认进入个人中心。
- 个人资料菜单对所有登录用户可用；只有 `ADMIN` 显示管理后台入口。菜单可见性不替代后台页面和 API 的服务端鉴权。
- `/admin/auth/login` 仅重定向到 `/login?next=/admin/mm`。旧管理员认证 API 为兼容适配器，密码校验、限流及签发策略与普通登录共用，仍拒绝普通用户。
- `next` 仅允许规范的 `/admin/mm` 子路径和既有委托邀请地址。普通用户的后台返回目标被替换为 `/account`。

## 账号记忆与免登录

两个选项互相独立，首次访问默认均不勾选。

| 选项 / 场景 | 行为 |
| --- | --- |
| 记住账号 | 成功登录后只在当前浏览器保存用户名或邮箱；取消勾选立即删除。旧管理员账号键迁移到 `sv_remembered_identifier`。存储异常不阻断登录。 |
| 不勾选免登录 | Cookie 不设置持久化期限；服务端初始有效期 12 小时，真实活动可续期。 |
| 勾选 7 天内免登录 | Cookie 与会话固定到本次认证后第 7 天；中途不访问也不提前过期。 |
| 注册自动登录 | 使用非持久会话。 |
| 钱包登录 | 遵循同一页面的免登录选择；不会自动重连后直接认证。 |

**所有会话的绝对期限都是 `createdAt + 7 天`。** 续期不能改变认证时间、重新签发 Token 或越过此期限。非持久会话每次成功续期最多延长至当前时间后 12 小时；空闲时限按最后一次成功续期计算。关闭浏览器不等同于服务端撤销会话，需使用“退出登录”主动注销。

## 续期接口与客户端

`POST /api/auth/session/renew`，同源请求，JSON 请求体为 `{}`。客户端不能指定到期时间。成功响应沿用 `code/message/data` 格式：

```ts
{
  user: SessionUser;
  expiresAt: string;          // ISO 时间
  absoluteExpiresAt: string;  // 首次认证后 7 天
  persistent: boolean;
}
```

- `GET /api/auth/session` 保持只读，仍返回用户 DTO 或 `null`。
- 非法来源返回 403，非法字段返回 400，失效会话返回 401 并清除 Cookie，超过请求频率返回 429。
- 客户端在页面可见且已登录时根据页面切换、聚焦、点击、键盘或滚动触发检查，正常续期按 5 分钟节流；没有无条件后台保活。
- 临时网络故障不直接注销，后续活动可重试；401 会清理身份相关缓存并刷新权限边界。
- 退出、改密导致失效或切换身份时，取消旧查询并通知其他标签页。通知只包含变更信号，不广播 Token 或用户资料。
- Token 只在 HttpOnly Cookie 中传递，数据库仅保存哈希。生产 Cookie 设置 `Secure`、`SameSite=Lax`；认证响应禁止缓存。

## 升级与回退

数据库修订 18 的 `20261015000000_bounded_sessions` 迁移在三种数据库中增加 `persistent` 字段，并**一次性撤销全部旧会话**，不删除会话记录、用户、钱包绑定或 MCP Key。新用户会话必须在迁移成功后创建。

发布前备份并在隔离数据库演练，维护窗口内停止旧实例，迁移成功后再启动新版本，禁止新旧会话策略混跑。升级失败不得把数据库标记为就绪。

优先向前修复。不要直接用仅支持旧 schema revision 的应用打开新版数据库，也不要通过恢复旧会话或修改认证时间回退安全策略。任何恢复流程都必须保持旧会话失效。

## 回归入口

- 单元和临时 SQLite 集成测试：会话时间边界、Cookie、限流、兼容 API、权限、账号记忆、跨标签缓存与并发续期。
- `npm run prisma:validate`：三种数据库模型校验；另需在隔离 PostgreSQL / MySQL 上执行迁移演练。
- 构建后可运行真实生产服务冒烟：

```sh
npm run build
RUN_AUTH_PRODUCTION_SMOKE=1 npm test -- src/server/auth/production-smoke.integration.test.ts
```

冒烟测试创建独立临时应用目录与 SQLite 数据库，运行正式迁移及 standalone 服务，通过合成账号检查登录、旧入口重定向、角色权限、续期和退出，最后清理。它不使用现有业务数据库，不替代浏览器人工验收或 HTTPS 部署检查。
