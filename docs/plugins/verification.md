## 本轮实现与收敛

- 插件及 SDK 统一迁入根目录 `plugins/`，不再保留集成目录下的第二份实现。官方目录使用内置 JSON；实际版本与下载仍查询 GitHub Release。
- 只安装 source-v1 源码 ZIP。打包 CLI 不编译，宿主以固定编译规则、独立 Worker、单并发和超时进行编译，不执行插件构建脚本或安装任意 npm 依赖。
- 编译在数据库维护写锁之外；成功后重新核对安装 generation，再迁移/切换。错误源码不替换旧安装。运行缓存缺失或校验失败可从可信源码重建，源码损坏可以重新上传同一 ZIP 修复。
- 源码、归档、编译产物、暂存与升级快照均按插件 ID 归入 `APP_DATA_PATH/plugins/{pluginId}`。整站恢复日志放在专用 `slothvault.restore` 子目录。主数据库仍负责安装状态、配置、任务和业务表。
- 移除自动安装及宿主生成的旧 seed/卡密 bundle；启动不因源码目录存在而建插件业务表。手动安装建表，启用开放服务，禁用保留数据，清理卸载才删自有表。
- 卡密采用普通命名空间表、明文码与批次明细，保留权限、一次核销、事务积分入账和幂等凭据。兑换为独立账户页面，不再注入积分中心；页面与插槽分别布局。
- 管理安装弹窗拆分官方/手动入口；GitHub 仓库选择折叠为高级选项。SDK 打包器移除已不用的编译依赖，宿主保留生产安装编译所需依赖闭包。
- 插件发布仅验证版本/结构并归档源码；独立 verify-plugins 工作流运行类型和行为测试。主应用镜像发布仍依赖三库验证。SDK 自身发布才构建 SDK 产物。
