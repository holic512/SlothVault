## 来源与数据边界

- **源码基线**：`14de20bf5cc7f75bdaadf116581f0a7c3788c5c3`，应用版本 `2.7.9`；使用该版本已构建的 Next.js standalone 服务，拍摄期间未修改应用源码或样式文件。

- **内容**：1 个演示项目、2 个发布版本，每版 8 篇文档，以及 4 篇独立文章。首页与正文依据仓库已有文档整理，使用当前版本的克隆、正文更新及发布 API 修订演示版本，发布内容没有直接改库。
- **身份**：公开页面由独立访客会话拍摄；账户与后台使用已获授权的本地测试管理员，显示名为“演示管理员”。截图不包含密码、会话凭据、个人业务资料或真实账本记录。

- **界面**：中文、单色编辑风格、标准卡片。明亮与暗黑模式通过产品内主题设置切换；项目文档的明暗截图使用相同内容、位置和桌面视口。
- **工具**：使用 `agent-browser` 的两个任务独立会话，没有读取或复用系统浏览器的 Cookie、Token 或登录态。

截图展示实际应用渲染的界面与示例内容，首页并非新安装后的默认内容。演示数据与真实站点分离。
