# UI 尺寸与阅读排版规范

## 字号与主题

字号以 `src/styles/tokens.css` 为准，采用 `rem`，不锁定根字号，尊重用户的浏览器字体设置和缩放。下表是默认根字号 16px 下的显示尺寸。

| 层级 | 桌面 | 移动端（≤640px） |
| --- | --- | --- |
| UI 正文 / 次要说明 / 辅助标签 | 15 / 13 / 12px | 15 / 13 / 12px |
| 普通页面标题 | 28px | 24px |
| 阅读页面标题 | 32px | 28px |
| 阅读正文 | 16px | 16px |
| 正文 H1 / H2 / H3 | 28 / 24 / 20px | 26 / 22 / 18px |
| 正文 H4 / H5 / H6 | 18 / 16 / 16px | 18 / 16 / 16px |
| 首页展示标题 | 36px | 28px |

正文行高为 1.8，标题行高为 1.35。阅读标题和正文跟随当前主题的 `--sv-font-body`，不在页面内硬编码其他字体。不要为普通标题使用随视口不断放大的字号；特殊展示需求必须明确区分用途。

Ant Design 的基础数字字号为 15px、次要字号为 13px，标题通过 CSS token 对齐；修改这些层级时须同步检查组件主题与基础样式，不重做控件布局。

## 管理后台字体规范

`/admin/mm` 使用独立的紧凑字体层级，覆盖管理页面、移动端导航、弹窗、抽屉、下拉选项和消息提示。后台专用字号在 `tokens.css` 的 `--sv-admin-font-*` 中定义；以下尺寸均以默认根字号 16px 为基准。登录、初始化、公开页面及个人中心继续使用原有规则。

| 用途 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面主标题：仪表盘、委托、模板、编辑器、设置子页 | 18px | 600 | 1.4 |
| 弹窗、抽屉标题 | 16px | 600 | 1.5 |
| 卡片、分区标题，包括“需要关注” | 12px | 600 | 1.5 |
| 正文、表格、表单标签与输入内容 | 13px | 400 | 1.6 |
| 按钮、页内导航、下拉选项 | 13px | 400；强调或选中 600 | 1.5 |
| 侧栏与面包屑 | 12px | 400；当前项 600 | 随控件垂直居中 |
| 表头、状态标签 | 12px | 表头 600，标签 400 | 1.5 |
| 描述、帮助、时间等次要信息 | 12px | 400 | 1.6 |
| 导航分组、图表刻度、紧凑计数 | 11px | 400 | 1.5 |
| 概览主要统计数字 | 24px；≤640px 时 22px | 600 | 1.2 |
| 卡片内次级统计数字 | 18px | 600 | 1.3 |

- 沿用当前主题的 `--sv-font-body`，页面标题与界面正文使用相同字体；字距保持正常。数字使用 `tabular-nums`，不再为同类文字添加零散字号或中间字重。
- `AdminTypographyProvider` 嵌套在管理端鉴权边界内，继承全站颜色、风格与语言，仅覆盖字体 tokens。内部 `App` 提供本地 `App.useApp()` 上下文，使确认弹窗、message 和 notification 使用后台主题；不要改用脱离上下文的静态 API。
- Ant Design 数字 tokens 与上表同步；`admin-typography.module.css` 将实际界面文字映射到 `rem`。页面与 portal 共用 `scope` 类，浮层通过 `ConfigProvider` 的语义 `classNames` 接入，自定义 portal 显式带上该类。不要将完整后台布局类附加到浮层，也不要通过 `body` 或全局根字号压缩页面。
- 共享委托组件使用 `admin-commission-workspace` 标记，仅管理端应用紧凑规则。编辑器工具栏、帮助与状态区使用后台字号；源码输入层与高亮层同时使用 13px、1.72 行高，避免光标与内容错位。
- `MarkdownView` 的文章、笔记、首页和合同正文继续使用下方阅读规范，保持预览、公开阅读和打印一致。封面占位字、关闭符号等图形不属于正文层级。
- 图表使用实际 SVG 视口尺寸计算坐标，不用固定 `viewBox` 缩放文字；窄屏降低日期刻度数量，保留首尾日期。检查折叠侧栏和浏览器字体放大后的刻度间距。

## 阅读宽度与间距

- 正文可用宽度最大 760px，不含外围内边距；带侧栏的文档须单独为侧栏分配空间。
- 页面左右留白：桌面至少 48px、平板（≤1024px）32px、移动端 24px；窄编辑预览采用 16px 内边距。
- 段落间距 16px，章节上间距 32px、下间距 12px。
- 代码块和宽表格在自身范围内滚动，不允许普通正文撑宽整页；图片不超过内容宽度且保持比例。
- 标题保留锚点，默认不显示下划线，悬停与键盘焦点有反馈，滚动避开固定导航。
- 首页采用开放式布局，不使用整页 Card 包裹，不通过放大正文来营造首屏效果。

## 共享渲染与作者兼容

`MarkdownView` 默认使用 `presentation="reading"`，适用于文档、笔记、文章、合同和回收站预览。系统首页、项目首页及其编辑预览显式使用 `presentation="landing"`。`MarkdownContentEditor` 接受同名属性，默认使用阅读模式。

页面只负责外围布局和页面标题，共享 Markdown 样式负责正文排版；不要在编辑器或页面样式中另设 H1–H6 字号，造成预览与实际阅读不一致。

保留安全过滤允许的作者内联字号、间距、颜色和布局，不改写存储内容。这些尺寸是系统默认规范，并非作者样式的强制上限；作者显式设置的大字号仍可能超出默认尺寸。不得通过全局 `!important`、整页缩放或修改安全白名单来强制压缩内容。

## 验证要求

检查代表性阅读页面与编辑预览，覆盖长标题、中英文、H1–H6、嵌套列表、宽表格、长代码、图片、提示块与自定义 HTML。确认浅／深色和两种主题风格下的尺寸一致、移动端无非预期横向溢出。

优先运行样式检查、相关 ESLint、类型检查和共享 Markdown 目标测试。仅在预期布局改变时更新对应视觉基准，不批量更新截图。
